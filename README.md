# HarnessBox

**DeepSeek 官方 Harness（DSH）内测版 · 一键启动器**

> 想体验 DeepSeek Harness，又不想折腾 Node、npm、命令行和环境变量？
> 下载 HarnessBox，双击即用。

HarnessBox 是一个 Windows x64 单文件启动器，把已经验证可运行的 DeepSeek Harness
运行环境（含 Node.js）打包进一个 `HarnessBox.exe`。下载后双击，它会自动在本机拉起
Harness 的 Web 界面，并用默认浏览器打开——操作简单到只需要点两下。

---

## 为什么需要它

| 传统方式 | HarnessBox |
| --- | --- |
| 先安装 Node.js / npm / pnpm | 无需安装任何环境 |
| 配置环境变量、敲命令行 | 无需命令行，无需环境变量 |
| 一步步搭建运行环境 | 下载一个文件，双击即用 |

HarnessBox 把「环境准备」这一步彻底省掉，让 Harness 的体验门槛降到最低。

---

## 核心特点

- **单文件、免安装**：一个 `HarnessBox.exe`，无需安装器，无需管理员权限。
- **双击即用**：首次运行自动释放内置运行环境，之后秒开。
- **自动打开浏览器**：启动完成后自动唤起系统默认浏览器，无需手动记地址。
- **托盘常驻**：常驻系统托盘，右键可「打开 HarnessBox」或「退出」，双击图标即可重新唤出页面。
- **退出干净**：退出时自动结束所有由它启动的后台进程，不残留、不拖慢系统。
- **自动选端口**：端口被占用时自动在可用区间内切换，一般无需手动干预。

## 快速开始

1. **下载** `HarnessBox.exe`（单个文件）。
2. **双击运行**。首次启动会自动解压运行环境，稍等几秒。
3. **开始使用**。浏览器自动打开本地 Harness Web 界面，直接上手。

> 提示：首次启动较慢属正常现象（正在释放运行环境）；之后再启动就快了。

## 重要：关于 API Key 与额度

**HarnessBox 只提供「启动器 + 运行环境」，不包含、也不赠送任何 API 额度。**

- 使用前需要自行准备并配置 **DeepSeek 官方 API Key**。
- 调用产生的费用按 DeepSeek 官方计费规则结算，与 HarnessBox 无关。
- 在界面中填入你的 API Key 后即可正常对话与使用。

## 使用说明

### 启动流程

双击后 HarnessBox 会自动完成以下步骤：

1. 检查是否已有实例在运行（避免重复启动多个后台服务）；
2. 首次运行（或版本更新）时，把内置运行环境释放到本机数据目录；
3. 启动本地 Harness Web 服务（监听 `127.0.0.1`，默认端口 `3081`，占用时自动在 `3080–3089` 间切换）；
4. 等待服务就绪后，自动打开默认浏览器。

### 托盘图标

运行后 HarnessBox 常驻通知区域（右下角）：

- **双击图标**：重新打开 Harness Web 页面；
- **右键 → 打开 HarnessBox**：打开页面；
- **右键 → 退出**：退出 HarnessBox 并关闭本地服务。

### 退出

从托盘选择「退出」即可。HarnessBox 会同时结束由它启动的后台进程，不会留下残留进程。

## 数据存放位置

所有运行数据都存放在本机用户目录，不污染系统、不写系统 PATH：

```text
%LOCALAPPDATA%\HarnessBox\
├─ runtime\     # 释放出的运行环境
├─ dsh-home\    # Harness 用户数据（会话 / 配置 / 存储）
└─ logs\        # 运行日志
```

- 不修改系统 PATH；
- 不写入系统环境变量；
- 彻底清除只需删除该目录并移除 `HarnessBox.exe`。

## 常见问题（FAQ）

**Q：双击后没反应或报错？**
A：检查是否被安全软件拦截；如首次运行失败，可查看 `%LOCALAPPDATA%\HarnessBox\logs\` 下的日志定位原因。

**Q：端口被占用怎么办？**
A：HarnessBox 会自动在 `3080–3089` 之间寻找空闲端口，一般无需手动处理。

**Q：需要自己安装 Node 或配置环境变量吗？**
A：不需要。运行环境已内置在 EXE 中，双击即用。

**Q：软件收费吗？**
A：HarnessBox 本身免费；但调用 API 产生的费用按 DeepSeek 官方计费，需自行承担。

**Q：如何退出？**
A：在系统托盘右键 HarnessBox 图标，选择「退出」。

**Q：数据存在哪里？如何彻底删除？**
A：见上文「数据存放位置」。删除 `%LOCALAPPDATA%\HarnessBox\` 目录并移除 EXE 即可。
